## 원본에 없는 화면 / 보완한 부분

- **홈·분석 본문**: 링크에 디자인이 없어 공통 토큰으로 보완했습니다. 최종 디자인 확인 필요.
- **결제수단 추가·수정, 예산 수정, 프로필 수정, 직접 서비스 입력, 삭제 확인**: Android 다이얼로그로 보완. 상세 디자인 필요.
- **날짜·시간 선택**: Android 기본 선택창 사용. 전용 커스텀 디자인이 필요하면 추가 제작.
- **오류·빈 상태·오프라인·권한 거부·토큰 만료·계정 탈퇴**: 서비스 수준의 화면과 문구를 추가해야 합니다.
- **다크 모드·태블릿·접근성 확대 글꼴 전용 레이아웃**: 현재는 밝은 테마와 모바일 세로 화면 중심입니다.
- **서비스 아이콘**: 원본에서 N/C/S 등 글자 마크로 되어 있으므로 그대로 표현했습니다. 실서비스 로고 사용 정책은 별도 결정해야 합니다.

## 원본 데이터의 불일치

- 등록된 6개 구독의 월 합계는 **66,900원**입니다.
- 결제수단 화면의 41,500원 / 25,400원은 개별 구독 금액 조합과 맞지 않습니다. 앱은 실제 연결된 구독을 합산하므로 **41,100원 / 25,800원**으로 표시합니다.
- 지난 이력의 38,600원에는 만료된 리디셀렉트 6,900원도 포함됩니다. 앱은 이를 명확히 하려고 요약 문구를 **정리한 구독의 월 환산 금액**으로 표시합니다.
- 내보내기 파일명과 D-day 기준일이 원본 화면 사이에서 다릅니다. 앱은 데모 기준일 2026-10-03으로 통일했습니다.

## 백엔드 및 서비스 정책 미완료

1. 이메일 인증·중복 확인·로그인·로그아웃·소셜 OAuth·세션 갱신·비밀번호 재설정.
2. 사용자별 데이터 동기화, 서버 검증, 충돌 해결, 삭제/복원 및 이력 정책.
3. 서비스 카탈로그·국가/통화별 요금제·가격 변동 정보. 지금 카탈로그 금액은 원본 예시입니다.
4. 실제 결제 내역 수집과 결제수단 연결. 현재 카드 앞 6/뒤 4자리만 로컬에 기록합니다.
5. 알림 예약: Android 알림 권한, FCM 토큰/서버 작업 또는 WorkManager 기반 로컬 예약, 재부팅·시간대 변경·중복 방지 정책.
6. 사용 여부 판단 기준과 사용자 확인 흐름. '미사용 확인 필요'는 실제 미사용을 단정하지 않습니다.
7. 연간 금액의 월 환산 반올림, 다중 통화, 결제일 공휴일 조정, 윤년·월말 정책 확정.
8. 정식 약관·개인정보 처리방침·운영 이메일·문의 접수/답변 및 계정 탈퇴.
9. 릴리스 서명키·스토어 아이콘·스플래시·Play Store 메타데이터·릴리스 빌드 설정.

## 로컬 데모 한계

- 결제 이력은 샘플이므로 내보내기 대상에서 제외됩니다.
- PDF는 앱에서 실제 생성합니다. 매우 긴 서비스 이름은 보고서에서 일부 축약될 수 있습니다.
- 상태는 SharedPreferences JSON으로 저장합니다. 데이터 규모가 커지면 Room + 마이그레이션으로 교체할 수 있습니다.
- 앱 프로세스 종료 후 구독·설정은 복구되지만 로그인은 항상 데모 시작 화면이며 작성 중인 미저장 양식 복구는 추가 작업입니다.
