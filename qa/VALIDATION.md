# 검증 기록

검증일: 2026-11-01 (KST)

환경: Windows, Java 17, Gradle 8.11.1, Android API 35 에뮬레이터(1080×2400, 420dpi).

## 완료한 검증

- 디버그 APK 생성 및 Android 에뮬레이터 설치·실행.
- 단위 테스트 7개: 월말·윤년·미래 첫 결제일·당일 결제, 연간 금액 환산, CSV 이스케이프, XLSX 구조.
- 기기 테스트 5개: 로그인/가입/목록/검색/상세/수정/카테고리/이력 이동, 마이/알림/결제수단/내보내기/도움말 이동, 저장 후 재읽기 및 이력 보관, PDF/XLSX 실제 파일 시그니처.
- 네이티브 화면 15개 캡처 및 Figma 원본과 시각 비교. 상단·카드 여백과 카테고리 시트 전체 펼침 조정.
- APK에 원본 SVG 112개가 포함되어 있고 빈 에셋 파일이 없음을 확인.

[화면 모음](contact-sheet.png)은 실제 에뮬레이터 캡처입니다. 개별 원본 캡처는 저장소에서 제외했습니다. 상태바 시각·키보드·시스템 내비게이션 영역은 Android가 표시합니다.

## 해결한 실행 환경 문제

Java 17 Windows 런처는 인수 파일을 시스템 문자셋으로 읽습니다. Gradle 데몬에 UTF-8을 강제하면 이 작업 폴더의 한글 경로가 테스트 JVM에 잘못 전달되어 `ClassNotFoundException`이 발생했습니다. 데몬은 기본 문자셋을 사용하고 테스트 출력 인코딩은 UTF-8로 설정해 해결했습니다.

## 아직 검증하지 않은 범위

- 실제 사용자 기기 및 API 26~34/36 이상의 호환성 매트릭스.
- 정식 계정 인증, 서버 연동, 푸시·이메일 수신, 외부 서비스의 실제 결제·해지.
- Play Store 릴리스 서명·배포.

실제 결제 이력은 아직 샘플이며, 데모 날짜는 2026-10-03으로 고정되어 있습니다.
